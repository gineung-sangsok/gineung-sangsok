# 마중 AI 데이터셋 요약 및 샘플 결과

> AI 라이프 솔루션 챌린지 제출 자료 — 실제 사용된 AI 결과물, 실행 스크립트, AI가 사용한 데이터에 대한 설명과 예시

## 0. 한눈에 보기

마중의 AI는 **사전 학습된 대규모 언어모델(GPT-5.4 mini)을 추가 학습(파인튜닝) 없이** 쓰고, 지역 데이터와 라벨링 데이터로 **프롬프트를 설계·검증**합니다. 그래서 "학습 데이터"는 아래 세 가지 역할로 나뉩니다.

| 데이터 | 규모 | 역할 |
|---|---|---|
| ① 입력 데이터 (임실군 가게·자원) | 가게 152곳 + 자원 368곳 = **520곳** | AI가 생활기능을 판단하는 대상 |
| ② 프롬프트 개발셋 `sample50` | 50건 (가게 30 · 자원 20), 정답 라벨 | 오류 사례를 보고 프롬프트 v1→v4를 다듬는 데 사용 |
| ③ 평가셋 `eval50` | 50건 (가게 40 · 자원 10), 2인 독립 라벨 + 합의 정답 | 프롬프트 개발에 쓰지 않은 **공정 평가** 전용 |
| ④ 공간·인구 데이터 | 131개 법정리, 인구 2.97만 명, 도로·정류장·이동장터 | 상속안 추천·공백 분석의 계산 입력 |

| 결과물 | 규모 | 파일 |
|---|---|---|
| LLM 생활기능 태그 | 518곳, 태그 760개 (확정 518 · 확인 필요 242) | `data/processed/tagging_llm.csv` |
| 키워드 규칙 태그 (베이스라인) | 498곳, 태그 632개 | `data/processed/tagging_keyword.csv` |
| 두 방법 비교표 | 기능 × 엔티티 | `data/processed/tagging_compare.csv` |
| 평가 결과 | 방법 × 기준 × 기능별 정밀도·재현율·F1 | `data/processed/tagging_eval_eval50.csv` |
| 상속안·공백 변화 | 폐업 등록 건마다 API로 계산 | `GET /closures/{id}/inheritance`, `/gap` |

## 2. 라벨링 데이터 (프롬프트 개발·평가용)

### 2-1. 라벨 기준
가게·자원 한 곳마다 F01~F04를 각각 **1(제공) / 0(제공 안 함)** 으로 적습니다. 이름·업종·주소만 보고 판단하며, 모델 결과와 상대 라벨은 보지 않고 각자 적습니다. ([docs/labeling_guide.md](labeling_guide.md))

| 기능 | 1로 적는 경우 | 0으로 적는 경우 |
|---|---|---|
| F01 생필품 | 공산품·가공식품을 판다 (슈퍼·편의점·마트·생활용품점·건어물) | 한 품목 전문점(정육·수산·채소·치즈), 관광지 매점·카페 |
| F02 신선식품 | 채소·과일·정육·수산·유제품 (농촌 슈퍼 포함) | 편의점, 건어물·젓갈, 생활용품점 |
| F03 무거운 상품 | 쌀·생수·연료 판매·배달 근거 (마트·하나로마트·곡물점) | 근거 없는 작은 슈퍼·상회 |
| F04 마을 거점 | 경로당·복지관, 법정리에 식료품점이 이곳뿐인 가게 | 그 외 |

### 2-2. 데이터셋

| 데이터셋 | 건수 | 뽑는 방법 | 정답 양성 수 (F01 · F02 · F03 · F04) | 파일 |
|---|---|---|---|---|
| `sample50` (개발셋) | 50 (가게 30 · 자원 20) | 업종·자원 종류별 고르게 무작위 | 18 · 17 · 5 · 22 | `data/labels/sample50.csv` |
| `eval50` (평가셋) | 50 (가게 40 · 자원 10) | sample50을 **제외**하고 새로 무작위 (`--seed 7`) | 24 · 27 · 2 · 18 | `data/labels/eval50.csv` |

- `eval50`은 라벨러 A·B가 따로 적은 뒤(`eval50_A.csv`, `eval50_B.csv`) 갈린 48칸을 라벨 기준으로 합의해 정답을 확정했습니다 (`eval50_disagree.csv`의 `final`).
- 라벨러 간 일치도(코헨 카파): 전체 **0.55** (F01 0.38 · F02 0.45 · F03 0.14 · F04 0.87)

**정답 라벨 예시 (`eval50.csv`)**

| 이름 | 업종·종류 | 법정리 | F01 | F02 | F03 | F04 | 판단 |
|---|---|---|---|---|---|---|---|
| 강진할인마트 | 슈퍼마켓 | 갈담리 | 1 | 1 | 1 | 0 | 이름에 "마트", 같은 리에 식료품점 여러 곳 |
| 지에스25전북 | 편의점 | 이도리 | 1 | 0 | 0 | 0 | 편의점은 신선식품·무거운 상품 근거 없음 |
| 갈마야채 | 채소/과일 | 갈마리 | 0 | 1 | 0 | 0 | 한 품목 전문점 → 신선식품만 |
| 당당경로당 | 경로당 | 도인리 | 0 | 0 | 0 | 1 | 경로당은 마을 거점 |

## 4. 샘플 결과

### 4-1. 생활기능 분리 — 실제 LLM 출력 (`tagging_llm.csv`)

**천일슈퍼** (덕치면 일중리 · 슈퍼마켓 · 같은 리 식료품점 1곳) — 시연 사례

| 기능 | 확신도 | 판정 | 근거 (모델 출력) |
|---|---|---|---|
| F01 생필품 | 0.95 | 확정 | 슈퍼마켓 업종의 일반 식료품점으로 라면, 휴지, 세제 같은 생필품과 공산품을 살 수 있는 곳으로 판단된다. |
| F02 신선식품 | 0.50 | 담당자 확인 | 슈퍼마켓이라 신선식품도 일부 취급할 가능성이 있지만, 구체 품목 정보가 없어 확인이 필요하다. |
| F03 무거운 상품 | 0.50 | 담당자 확인 | 일반 슈퍼마켓은 쌀이나 생수 같은 무거운 상품도 취급할 가능성이 있으나, 배달 여부나 실제 취급 품목은 확인이 필요하다. |
| F04 마을 거점 | 0.50 | 담당자 확인 | 같은 법정리의 영업 식료품점이 이곳뿐이라 주민들의 일상적인 물품 구입과 안부 확인이 이뤄지는 마을 생활거점 역할을 할 가능성이 있다. |

**업종별 비교 — LLM과 키워드 규칙**

| 이름 (업종) | LLM 결과 | 키워드 규칙 | 차이 |
|---|---|---|---|
| 임실축협하나로마트 (식품판매업) | F01 0.95 · F02 0.90 · F03 0.85 | F01 0.9 · F02 0.8 · F03 0.7 | 같은 판단 |
| 지에스25전북 (편의점) | F01 0.95 | F01 0.9 | 같은 판단 |

| 일중경로당 (경로당) | F04 0.95 — "주민이 모여 안부를 확인하는 마을 생활거점" | F04 0.9 | 같은 판단 |

### 4-2. 평가 결과 — 공정 평가셋 `eval50` (`tagging_eval_eval50.csv`)

| 방법 | 기준 | 정밀도 | 재현율 | F1 |
|---|---|---|---|---|
| 키워드 규칙 | 확정(0.6↑) | 0.79 | 0.69 | 0.74 |
| 키워드 규칙 | 확인 포함(0.4↑) | 0.75 | 0.85 | 0.79 |
| **LLM v4** | 확정(0.6↑) | **0.91** | 0.61 | 0.73 |
| **LLM v4** | 확인 포함(0.4↑) | 0.65 | **0.96** | 0.77 |

- LLM이 확정한 태그는 91%가 맞고, "확인 필요"까지 포함하면 실제 기능의 96%를 놓치지 않습니다 → AI가 확신할 때만 확정하고 나머지는 담당자에게 넘기는 설계가 데이터로 뒷받침됩니다.
- 개발셋(sample50)에서는 F1 0.90이었지만 평가셋에서 0.73으로 내려갔습니다. 개발셋 점수의 과대평가를 걷어 낸 값을 공식 성능으로 씁니다.
- 프롬프트 개선 과정과 버전별 결과: [docs/experiments/tagging_prompt.md](experiments/tagging_prompt.md)

## 6. 데이터 이용과 한계

- 공개 사업장·시설 정보와 통계 집계 인구만 사용하며, 개인정보는 다루지 않습니다.
- 원본 데이터(`data/raw/`)는 저장소에 올리지 않고 정제 결과만 공개합니다. LLM 응답 캐시도 `data/raw/`에 둡니다.
- 이동장터 정식 노선과 상점 운영시간은 공개되지 않아, 해당 추천은 모두 "담당자 확인"으로 표시합니다.
- 무거운 상품(F03)은 평가셋 정답 양성이 2건이라 기능별 점수의 신뢰도가 낮습니다.
