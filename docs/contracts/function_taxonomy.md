# 기능 체계 (v1.0, 10/13 회의 확정)

가게(폐업 예정 시설)와 상속 자원 양쪽에 **같은 코드**를 붙인다.

| 코드 | 기능 | 판단 기준 |
|---|---|---|
| F01 | 생필품 구매 | 공산품·가공식품 판매 |
| F02 | 신선식품 구매 | 채소·과일·정육·수산 등 냉장 상품 |
| F03 | 무거운 상품 구매 | 쌀·생수·연료 등 들고 오기 힘든 상품, 또는 배달 |
| F04 | 마을 생활거점 | 공동수령·모임·안부 확인 장소 |
| F05 | (예약) 택배 수령 | MVP 제외, 코드만 예약 |

## F04 판정 규칙
- 해당 법정리에 영업 중인 식료품점이 **1곳뿐**이면 F04 후보 (confidence 0.5 → "확인 필요")
- 마을회관(R03)은 기본 F04 제공

## confidence 기준
- **0.6 이상**: 태그 확정
- **0.4~0.6**: "확인 필요" (담당자 검토)
- **0.4 미만**: 버림

## 자원 유형 코드

| 코드 | 자원 유형 |
|---|---|
| R01 | 이동장터 노선 |
| R02 | 농협·지역마트 배송 |
| R03 | 마을회관·경로당 등 공동거점 |
| R04 | 복지기관·생활지원 서비스 (우체국 연계 복지 포함) |
| R05 | 인근 상점·사회적경제 조직 |
