# 기능 체계 (v0.1 초안, 10/13 확정 예정)

가게(폐업 예정 시설)와 상속 자원 양쪽에 **같은 코드**를 붙인다.

| 코드 | 기능 | 판단 기준 (예시) |
|---|---|---|
| F01 | 생필품 구매 | 라면·휴지·세제 등 공산품·가공식품 판매 |
| F02 | 신선식품 구매 | 채소·과일·정육·유제품 등 냉장 상품 판매 |
| F03 | 대용량·무거운 상품 구매 | 쌀·생수·LPG·비료 등, 또는 배달 가능 |
| F04 | 마을 내 생활거점 | 공동수령·모임·안부 확인 등 사람이 모이는 장소 기능 |
| F05 | (선택) 택배 수령 | 택배 대리 수령·보관 |

## 자원 유형 코드

| 코드 | 자원 유형 |
|---|---|
| R01 | 이동장터 노선 |
| R02 | 농협·지역마트 배송 |
| R03 | 마을회관·경로당 등 공동거점 |
| R04 | 복지기관·생활지원 서비스 (우체국 연계 복지 포함) |
| R05 | 인근 상점·사회적경제 조직 |
