# 상속안 추천 점수 기준 (#45)

- 날짜: 2026-10-28
- 코드: `track2_recommend/recommend.py` (점수·선택), `backend/store.py` (`recommend_candidates`, `ClosureStore.inheritance`)
- API: `GET /closures/{id}/inheritance` — 응답 형식은 계약 `Inheritance` 그대로

## 흐름
1. 폐업 가게의 기능 목록을 가져온다. 담당자가 PATCH로 고쳤으면 고친 목록을 쓴다. confidence 0.4 미만은 버린다.
2. 기능마다 같은 기능을 하는 후보를 모은다. 영업 중(ACTIVE·SEASONAL)인 가게, 경로당·복지기관, 면 단위 이동장터가 대상이다. 폐업 가게 자신은 뺀다.
   - 후보 태그 0.6 이상이면 그대로, 0.4~0.6이면 후보로 넣되 `needs_officer_check: true`
   - 가게 종류: 이름에 하나로·농협·농업협동조합 → R02, 그 밖 → R05. 자원은 원래 종류(R03·R04)
3. 5가지 점수(0~1)의 가중합으로 순위를 매기고, 기능마다 1위를 상속안으로 돌려준다.
4. 1위 점수가 0.45 미만이거나 후보가 없으면 `uncovered_functions`에 넣는다.

## 점수와 가중치

| 점수 | 가중치 | 계산 | 근거 |
|---|---|---|---|
| distance | 0.35 | 1 − 직선거리/10km (이동장터는 1) | 고령 주민에게 거리가 가장 큰 장벽. 10km는 면 경계를 넘는 거리 |
| service_area | 0.25 | 같은 리 1 · 같은 면 0.7(이동장터 0.8) · 다른 면 0.3 | 주민이 실제로 다니는 생활권 |
| delivery | 0.15 | 농협 배송(R02)·이동장터·무거운 상품(F03) 태그 0.4↑ → 1, 아니면 0 | 이동이 어려운 주민의 대안 |
| transport | 0.15 | 후보가 있는 리의 가까운 정류장 300m 이내 1 → 2km 0 (이동장터 1) | `accessibility_ri.csv` 도로 기준 거리 |
| hours | 0.10 | 운영 시간 정보가 없으면 0.5 + 담당자 확인 · 이동장터(주 1회) 0.3 | **운영 시간 데이터 없음** → 중간값, 가중치를 낮게 둠 |

가중치·기준값은 `recommend.py` 맨 위 상수(`WEIGHTS`, `MIN_SCORE`, `MAX_KM`, `HOURS_UNKNOWN`)에 모았다.

## 데이터 한계
- **이동장터(R01)**: 마을 명단이 공개된 것은 2026-02 시범 노선(임실읍, `mobile_market_route_ri.csv`)뿐이다. 임실읍은 시범 노선 마을이면 사유에 "시범 운영 노선에 포함된 마을"을 적고, 노선에서 뺀 이도리·성가리·두곡리에는 추천하지 않는다. 나머지 면은 `mobile_market_imsil.csv`(면 단위, 주 1회)로 같은 면에만 가정 노선으로 추천한다. 어느 쪽이든 9월 정식 노선 명단이 없어 항상 `needs_officer_check: true`다 (#10).
- **운영 시간**: 데이터가 없어 hours는 0.5로 두고 `needs_officer_check: true`로 표시한다. 지금은 모든 가게·자원 후보가 여기에 해당해 상속안 전부가 담당자 확인 대상이다. 후보에 운영 시간(`Candidate.hours`)이 채워지면 그 값을 쓴다.
- **거리**: 도로 거리가 아니라 직선거리(haversine)다. 산간 지역은 실제 이동 거리가 더 길다.
- 추천 사유는 점수 기반 문장 템플릿이다. LLM 사유는 다음 단계.

## 데모 결과 (closure_0001 · 덕치면 일중리 천일슈퍼)

| 기능 | 상속안 | 점수 | 확인 필요 |
|---|---|---|---|
| F01 생필품 | 임실 이동장터 (덕치면 가정 노선) | 0.88 | 예 (가정 노선) |
| F02 신선식품 | 임실 이동장터 (덕치면 가정 노선) | 0.88 | 예 (가정 노선) |
| F03 무거운 상품 | 임실농협하나로마트덕치점 (2.6km) | 0.76 | 예 (운영 시간 없음) |
| F04 마을 거점 | 일중경로당 (0.5km, 같은 마을) | 0.78 | 예 (운영 시간 없음) |

**해석**
- 이동장터는 거리·교통 점수가 1이라 같은 면에 있으면 F01·F02에서 거의 항상 1위가 된다. 실제 노선이 확인되기 전에는 "확인 필요" 표시를 보고 담당자가 판단해야 한다.
- 노선 데이터를 구하면 `mobile_market_candidates`가 리 단위 정차 여부를 보도록 바꾸면 된다.
