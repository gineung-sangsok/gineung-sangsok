# 기능 태깅 정답 라벨 기준

가게·자원 한 곳에 F01~F04를 각각 **1(제공) / 0(제공 안 함)** 으로 적는다. 기준은 `docs/contracts/function_taxonomy.md`와 10/26 A·B 합의를 따른다.

## 라벨링 방법
- 이름·업종·주소만 보고 판단한다. 현장 확인이 불가능한 것은 "그럴 가능성이 높으면 1"로 적는다.
- **모델 결과(`data/processed/tagging_*`)와 상대 라벨을 보지 않고** 각자 적는다. 일치도(카파)를 구하기 위해서다.
- 다 적은 뒤 `uv run python scripts/evaluate_tagging.py --agreement <A.csv> <B.csv>`로 갈린 칸을 뽑고, 둘이 합의해 정답을 확정한다.

## 기능별 기준

| 기능 | 1로 적는 경우 | 0으로 적는 경우 |
|---|---|---|
| F01 생필품 | 공산품·가공식품을 판다 (슈퍼·편의점·마트·생활용품점·건어물·제과) | 한 품목 전문점(정육·수산·채소·치즈), 관광지 매점·카페 |
| F02 신선식품 | 채소·과일·정육·수산·유제품을 판다 (농촌 슈퍼 포함, 치즈 판매장) | 편의점, 건어물·젓갈, 생활용품점 |
| F03 무거운 상품 | 쌀·생수·연료를 팔거나 배달한다 (이름에 마트·하나로마트, 곡물점) | 근거 없는 작은 슈퍼·상회 |
| F04 마을 거점 | 경로당·복지관, 법정리에 영업 중인 식료품점이 이곳뿐인 가게 | 그 외 |

## 10/26 합의 사항
- 다이소·천원숍: F01
- 건어물·젓갈: F01 (가공식품), F02 아님
- 치즈 판매장: F02만, F01 아님
- 휴게소 안 편의점: 상품은 팔므로 **라벨은 F01=1**. 모델은 주민 접근성 때문에 0.5(확인 필요)로 두므로 "확인 포함" 기준에서 맞은 것으로 본다.
- 슈퍼마켓 F02: 라벨은 1. 모델은 0.5(확인 필요)로 두고 공백 계산에서 "부분 제공"으로 센다.
